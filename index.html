문자 작성

게스트 정보를 입력하면 템플릿에 자동으로 채워집니다

문자 작성 사용 방법

  • ① 게스트 정보 — 이름과 연락처 입력. 연락처는 자동 하이픈.
  • ② 숙소/호실 — 보낼 대상 호실을 고르면 해당 와이파이·도어락이 자동 반영됩니다.
  • ③ 체크인/체크아웃 — 날짜 버튼을 눌러 입·퇴실을 한번에 선택. 인원·금액도 여기서.
  • ④ 템플릿 선택 — 단계별 템플릿을 고르면 우측 프리뷰에 실제 문자가 나타납니다.
  • {변수}는 {이름}, {입실시간}, {호실명}, {와이파이이름}, {결제금액} 등이 자동 치환됩니다.
  • 문자 앱 열기를 누르면 iOS/Android 문자 앱이 열리고 발송 이력에 자동 기록됩니다.
  • 예약 저장으로 이 예약을 "예약 → 예약 관리"에 보관할 수 있어요.

템플릿 관리

단계별 문자 템플릿을 추가·편집·삭제합니다

📚 템플릿 관리 사용 방법

  • 6개 단계 — 문의·예약전·예약확정·입실전·입실후·퇴실별로 템플릿을 모아놨어요.
  • 추가 — 각 단계의 + 템플릿 추가를 눌러 새 문자를 만듭니다.
  • 편집 — 템플릿 제목 행을 클릭하면 펼쳐지고, 제목·본문을 수정 후 저장.
  • 복제 — 비슷한 문자를 빠르게 만들 때 사용 (해당 단계에 복사본 추가).
  • 사용 가능한 변수: {이름} {입실시간} {퇴실시간} {박수}(입실~퇴실 밤 수) {인원}(「2인」 꼴) {인원수} {결제금액} {연락처} {숙소명} {호실명} {숙소주소} {입금계좌} {와이파이이름} {와이파이비번} {도어락비번} {전화뒷자리}(손님 전화번호 끝 4자리) {주중요금} {주말요금} {반려견동반}(예약 메모에 반려견이 있으면 줄바꿈 뒤 「반려견 동반 (소형견 1마리)」, 없으면 아무것도 안 넣음 — 인원 줄 끝에 붙여 씀) {바비큐확정} {바비큐입실}(11~2월 입실인데 바비큐를 예약·문의한 손님(메모 바비큐 ○/문의, 고객 탭 바비큐 체크)이 아니면 「11월부터 2월까지는 바비큐가 불가합니다. 이점 양해부탁드립니다」 문장, 그 외에는 종전 바비큐 안내 문장. 바비큐를 하신다고 한 손님은 입실 문자 끝에 「바비큐 하실 시간을 답장으로 알려주시면 그릴 준비해 두겠습니다」가 붙음)
  • 변경 사항은 즉시 문자 작성에도 반영됩니다.

예약 관리

저장된 예약이 없습니다

예약 사용 방법

  • 다가오는 · 지난 · 전체 — 다가오는 예약은 오늘·머무는 중 → 7일 안 → 달별로 묶여요. 검색 칸은 이름·전화 뒷자리·메모로 찾습니다.
  • 줄 누르기 — 펼쳐서 연락처·메모·문자 단계를 보고, 문자 작성·수정·삭제를 합니다.
  • 문자 칩 (예약확정 · 입실 · 퇴실) — 초록 보냄 · 파랑 날짜 승인됨 = 승인 끝, 그날 봇이 보냄 · 흰 칸 날짜 예정 = 아직 승인 전, 이틀 전에 승인 요청이 와요 · 노랑 승인 대기 · 빨강 확인 필요 · 회색 직접 보냄 · 옅은 기록 없음. 메모 앞 보라 표시는 반려견·바비큐예요.
  • 새 예약 — 이름·전화·날짜·인원·금액을 직접 넣어요. 문자 작성 탭의 예약 저장으로도 추가됩니다.
  • 임시 휴무 — 사정으로 손님을 못 받는 날을 넣으면 봇이 10분 안에 네이버·에어비앤비 날짜를 막아요. 휴무를 취소해도 봇은 풀지 않으니 두 곳에서 직접 열어 주세요.

고객 관리

예약이 없습니다

고객 관리 사용 방법

  • 한 줄 = 고객 한 명 — 같은 전화번호로 온 예약을 한 고객으로 묶습니다. 두 번 이상 온 고객은 아래에 숙박 줄이 붙습니다(최근 먼저). 이름·전화·숙박일은 예약 관리에서 자동으로 옵니다.
  • 반려견 · 바비큐 · 리뷰 — 숙박 줄의 버튼을 누르면 바로 저장됩니다(로그인 상태에서만). 「자동」 표시는 예약 메모를 보고 자동으로 켠 것, 누르면 직접 정한 값이 됩니다. 진초록 ✓는 직접 켠 것입니다. 리뷰는 퇴실이 지난 숙박에만 나옵니다.
  • 보기 — 재방문은 두 번 이상 온 고객, 리뷰 없음은 다녀갔는데 리뷰 표시가 안 된 고객입니다.
  • 검색 — 이름, 전화번호 일부, 메모로 찾습니다.

매출

확정 예약 기준

통계 읽는 법

  • 매출 — 확정 예약의 결제금액 합. 취소 제외. 월은 입실일 기준. 에어비앤비는 수수료 반영가라 채널별로 따로. 반려견·바비큐 추가금은 결제금액에 없으면 빠집니다.
  • 요일별 매출 — 손님이 잔 밤의 요일로 나눕니다. 금요일 입실 2박이면 결제금액을 반씩 금·토 밤에. 「금」은 금요일 밤(토요일 아침 퇴실).
  • 점유율 — 그 달에 손님이 자는 밤 수 ÷ 그 달 일수. 미래 달은 지금까지 예약된 밤 기준.
  • 네이버 유입 — 봇이 매일 아침 스마트플레이스 통계에서 가져옵니다(전날까지). 유입 = 플레이스를 본 수, 예약 페이지 = 예약 화면까지 온 수, 신청 = 예약 신청.
  • 그래프 — 막대·점에 마우스를 올리면(폰은 길게) 숫자가 보입니다.

요금 계산

날짜와 인원만 고르면 숙박 요금이 자동 계산됩니다

요금 계산 사용 방법

  • 기본 요금 — 숙소 프로필의 호실 카드에서 주중·주말 요금을 입력하세요.
  • 상세 요금 — 호실 카드의 요금 상세 설정에서 공휴일·기준인원·연박할인·기간요금을 설정할 수 있어요.
  • 계산 순서 — 특별기간 > 공휴일 > 주말(금·토) > 주중 순으로 하루씩 계산해 합산합니다.
  • 공휴일 전날 — 숙박 요금은 "그날 밤" 기준이라 공휴일 전날 밤도 공휴일 요금으로 볼 수 있어요. 호실의 공휴일 요금 적용에서 당일+전날 / 전날만 / 당일만을 고르세요.
  • 옵션 요금 — 미취학아동·강아지·바베큐는 숙소 프로필의 옵션 요금에서 켜면 여기에 나타나요.

숙소 프로필

숙소 프로필 사용 방법

  • 숙소 정보 — 이름·주소·계좌를 입력하면 {숙소명} {숙소주소} {입금계좌} 변수에 자동 반영됩니다.
  • 호실 관리 — 호실마다 와이파이·도어락·요금을 따로 저장. 다중 호실 운영에 편리합니다.
  • 도어락 자동 — 손님 전화번호 뒷자리 자동 사용을 체크하면 게스트마다 도어락 비번이 자동 생성돼요.
  • 주중·주말 요금 — 호실 카드에서 입력하면 {주중요금} {주말요금}에 선택된 호실 기준으로 반영됩니다.
  • 요금 상세 설정 — 호실 카드 안에서 공휴일 요금·기준/최대 인원·연박 할인·기간별 요금을 설정하면 요금 계산 페이지에 반영돼요.
  • 특별 기간 · 옵션 요금 — 성수기/할인기간 등록과 아동·강아지·바베큐 요금은 아래 카드에서 관리합니다.
  • 내보내기 / 가져오기 — 설정·템플릿·예약 전체를 JSON 파일로 백업·복원할 수 있어요.
  • 홈 화면에 바로가기 추가 — 모바일 브라우저에서 누르면 PWA 앱처럼 설치됩니다.

한 줄 = 예약 한 건 · 이름·전화·숙박일은 예약 관리에서 자동으로 와요. 같은 전화번호면 방문 횟수로 묶어 셉니다.
반려견 · 바비큐 · 리뷰 · 칸을 누르면 바로 저장돼요(로그인 상태에서만). 반려견은 예약 메모에 있으면 자동으로 표시돼요.
요금 계산
자동 계산 · 요금 계산 페이지에서 호실·날짜·인원을 고르면 하루씩 계산해 합산합니다.
· 우선순위: 특별기간 > 공휴일 > 주말(금·토) > 주중
요금 설정 · 숙소 프로필 → 호실 카드의 요금 상세 설정에서 공휴일 요금·기준/최대 인원·연박 할인·기간별 요금을 입력하세요.
특별 기간 · 숙소 프로필의 특별 기간 카드에서 성수기·할인기간을 등록하면 호실마다 기간 요금을 따로 정할 수 있어요.
옵션 요금 · 미취학아동·강아지·바베큐 요금을 켜면 요금 계산에 반영됩니다.
예약에서 바로 계산 · 새 예약 추가 창의 요금 자동 계산 버튼으로 금액이 자동 입력돼요.
발송 이력
자동 저장 · 문자 앱 열기를 누른 모든 발송 기록이 자동으로 쌓입니다.
다시 보내기 · 이력의 문자 내용 그대로 문자 앱이 다시 열려요.
복사 / 삭제 · 이력별 개별 조작, 전체 삭제로 일괄 초기화도 가능.
봇이 보낸 문자 · 전달 상태가 함께 보여요. 봇으로 다시 보내기를 누르면 10분 안에 봇이 같은 문자를 다시 보내요(08~21시).
통계
매출 · 확정 예약의 결제금액을 입실일 기준 월별·채널별·요일별로 보여요. 취소는 빼고 따로 셉니다.
고객 · 고객 수·재방문 고객과 반려견 동반·바비큐 비율을 봅니다(예약 메모와 고객 관리 체크 기준).
네이버 유입 · 봇이 매일 아침 스마트플레이스 통계를 가져와요(전날까지). 검색어·들어온 곳·성별·연령도 여기서 봐요.
분석 · 예약·유입 숫자를 읽어 지금 볼 것을 알려 주고, 봇 메모를 함께 보여요.
